# BIYOU NOTE (MyApp01)

スキンケア・お薬・サロン・美容費を一元管理する、自分専用の美容管理アプリです。

## コンセプト

- 記録は事実ベース。過剰な煽り文言や励まし文言は入れない
- 肌・お薬の記録はあくまで「記録ツール」。診断や治療方針の判断はしない(病院での提示用)
- 全体のUIはシンプルで見やすく、淡い水色×白を基調とした上品でキラキラした雰囲気にする

## 使い方(このアプリの動かし方)

ビルド作業は不要です。`index.html` をブラウザで開くか、GitHub Pages に公開したURLを開くだけで動きます。

- 公開URL: `https://sakana01-hash.github.io/MyApp01/` (Pages有効化後に利用可能)

## データについて

このアプリのデータ(肌の記録・お薬の情報など)は、すべて**使っている端末の中だけ**に保存されます。サーバーには送信されません。リポジトリが公開(public)でも、個人の記録が外部に漏れることはありません。

機種変更などに備えて、アプリ内の「データのエクスポート」機能で定期的にバックアップを取ることをおすすめします。
